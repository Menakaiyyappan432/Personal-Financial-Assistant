Personal Financial Assistant & Expense Tracker 📊

A sleek, modern Full-Stack Financial Management Dashboard built with Python (FastAPI) and JavaScript . This app helps users seamlessly track their monthly salary, fixed expenses like Rent/PG, dynamic daily spending, and visual analytics with a glassmorphism dark-mode UI. 

Key Features :

💵 Monthly Salary & Rent Tracking: Automatically calculates remaining balance based on a fixed monthly salary (₹25,000) and fixed rent (₹7,000).
🍩 Interactive Category Chart: Integrated Chart.js doughnut visualization for real-time category-wise expense breakdown.
⚡Quick Log Shortcuts: Preset chips for instant 1-tap logging of daily frequent expenses (e.g., Petrol ⛽, Food/Juice 🍕, Auto 🛺). 
🏷️ Smart Categorization & Icons: Auto-mapped dynamic emoji icons for Petrol ⛽, Food/Juice 🍕, Travel 🚗, Shopping 👗, and more.
🎨 Glassmorphism Dark UI:Ultra-responsive dark theme styled with dynamic glow accents, micro-animations, and clear financial stat cards.
💾 Data Persistence: Lightweight local data persistence using structured JSON handling.

🛠️ Tech Stack & Tools

🐍 Language: Python
⚡ Backend Framework: FastAPI
 🌐 Frontend: HTML, CSS (Glassmorphism & Neon Accents), JavaScript (Fetch API)
 🦄 Server: Uvicorn
 📁 Data Storage: JSON File Storage
