💰 Personal Financial Assistant

A sleek Full-Stack Expense Tracker built with Python (FastAPI) and JavaScript. This app helps users manage their daily spending with a modern, dark-themed interface.

🚀 Key Features:
- FastAPI Backend:** High-performance REST API for data management.
- Dynamic Dark UI:** Modern dashboard with automatic category icons.
- Smart Categorization:** Automatically identifies Food, Travel, and Shopping.
- Data Persistence:** Uses JSON file handling for local storage.

🛠️ Tech Stack:
- Language:Python 3.x
- Framework: FastAPI
- Frontend: HTML5, CSS3, JavaScript (Fetch API)
- Server: Uvicorn
